# Legal

Five use cases for law firms, in-house legal teams, and legal-tech platforms. Each example turns multi-step legal reasoning into a structured, repeatable AI workflow.

| Use Case | Patterns | Integration |
|----------|---------|-------------|
| [Contract Risk Review](./contract-risk) | RiskAssessor + RiskMitigator + ImpactAssessor | LlamaIndex RAG over clause library |
| [Legal Research Synthesis](./legal-research) | SynthesisBuilder + AnalogicalReasoner + CrossDomainSynthesizer | LangChain memory chain |
| [Case Strategy Workshop](./case-strategy) | DecisionFramework + ScenarioPlanner + StakeholderMapper | CrewAI simulation |
| [Regulatory Impact Assessment](./regulatory-impact) | ImpactAssessor + ConsequentialistAnalyzer + StakeholderEthicsAssessor | Raw Context + QualityMetrics CI |
| [Client Brief Simplifier](./client-brief) | SimplificationEngine + AudienceAdapter + PersuasionFramework | Blueprint + streaming FastAPI |
