# Government

Five use cases for government agencies, public sector consultants, and policy teams. These examples show how structured context engineering brings consistency and auditability to high-stakes public work.

| Use Case | Patterns | Integration |
|----------|---------|-------------|
| [Policy Impact Analysis](./policy-impact) | ImpactAssessor + ConsequentialistAnalyzer + StakeholderEthicsAssessor | Raw Context + quality audit trail |
| [Public Communication Simplifier](./public-communication) | SimplificationEngine + AudienceAdapter + ClarityOptimizer | Blueprint + LangChain streaming |
| [Regulatory Compliance Audit](./compliance-audit) | SystemHealthAuditor + AnomalyDetector + EthicalFrameworkAnalyzer | LlamaIndex RAG over regulation docs |
| [Crisis Response Planning](./crisis-response) | ScenarioPlanner + RiskMitigator + FutureScenarioPlanner + StakeholderMapper | CrewAI emergency response crew |
| [Budget Allocation Analysis](./budget-allocation) | CostBenefitAnalyzer + ResourceAllocator + MultiObjectiveOptimizer | Blueprint + OutputEvaluator |
