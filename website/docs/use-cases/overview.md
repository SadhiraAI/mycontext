# Use Cases

Real, runnable examples of mycontext-ai solving domain-specific problems across 8 industries. Each use case mixes multiple cognitive patterns, demonstrates a specific integration style, and shows what you actually get from the output.

## Integration Styles Used

Every use case picks the integration style that fits the problem — raw `Context`, LangChain LCEL, CrewAI multi-agent, AutoGen, LlamaIndex RAG, Blueprint, or Agent Skills. Most examples combine two or three.

## Patterns Coverage

These use cases collectively cover all 87 cognitive patterns — 16 free and 71 enterprise. Enterprise patterns require [activating a license key](/docs/advanced/enterprise-license).

mycontext.activate_license("MC-ENT-YOUR-KEY")
