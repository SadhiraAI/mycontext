# Education

Five use cases for edtech platforms, universities, and learning teams. These examples show how to build AI learning experiences that adapt to learners rather than deliver static content.

| Use Case | Patterns | Integration |
|----------|---------|-------------|
| [Adaptive Curriculum Builder](./adaptive-curriculum) | ScaffoldingFramework + ZoneOfProximalDevelopment + CognitiveLoadManager | LangChain with memory |
| [Socratic Tutoring Agent](./socratic-tutoring) | SocraticQuestioner + MetacognitiveMonitor + LearningFromExperience | AutoGen tutor loop |
| [Assessment & Rubric Designer](./assessment-rubrics) | RubricDesigner + FormativeAssessmentFramework + SummativeEvaluator | Blueprint |
| [Concept Explanation Engine](./concept-explanation) | ConceptExplainer + AnalogicalReasoner + MetaphorGenerator | Raw Context + CAI measurement |
| [Research Literature Review](./literature-review) | HypothesisGenerator + CrossDomainSynthesizer + SynthesisBuilder | LlamaIndex + TemplateBenchmark |
