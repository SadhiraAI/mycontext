# USPTO Provisional Patent Submission Verification

This checklist is based on **37 CFR 1.51(c)** and the official [USPTO Provisional Application for Patent](https://www.uspto.gov/patents/basics/apply/provisional-application) requirements. Use it to confirm you are submitting the right items.

---

## Official Requirements (37 CFR 1.51(c))

A **complete** provisional application must include:

1. **Cover sheet** identifying the application as provisional and the required data (see below).
2. **Specification** that satisfies **35 U.S.C. 112(a)** (written description of the invention).
3. **Drawings**, when necessary to understand the invention.
4. **Prescribed filing fee** (and application size fee if over 100 sheets).

The USPTO generally expects:

- **Language:** English ✅  
- **Paper size:** 8½ × 11 in (or A4) – PDF/print from your HTML is standard ✅  
- **Margins:** At least ¾" (top, bottom, sides) – your HTML uses 1" margins ✅  
- **Font:** Nonscript (e.g. Times New Roman), 12 pt preferred ✅  
- **Spacing:** 1½ or double spacing for specification – your HTML uses 1.5 line height ✅  

**Conclusion:** Your specification format is consistent with USPTO expectations. Electronic filing via Patent Center uses your PDF/DOCX; the Office does not reject a filing date solely for minor format issues.

## 7. Standard Submission Flow (Patent Center)

1. Log in to **Patent Center** (https://patentcenter.uspto.gov/).
2. Start a **new provisional** application.
3. Complete **Web ADS** (inventor name, residence, title, correspondence address). This satisfies the cover sheet.
4. Upload the **specification** (your PDF or DOCX).
5. Upload the **drawings** (your figures PDF or individual images).
6. Pay the **filing fee** (and application size fee if applicable).
7. Submit the application.
