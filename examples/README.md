# Examples

This folder contains Jupyter notebooks demonstrating mycontext usage.

## 📓 Available Notebooks

### 1. Getting Started (`getting_started.ipynb`)
**Quick introduction** to mycontext basics

- Simple context creation
- Using cognitive patterns
- Basic exports
- LLM integration examples

**Time:** 15-20 minutes

---

### 2. Complete Guide (`mycontext_complete_guide.ipynb`)
**Comprehensive tutorial** from beginner to advanced

**12 Sections:**
1. Introduction & Setup
2. Core Concepts (Directive, Guidance, Constraints)
3. Basic Usage
4. **50 Cognitive Patterns** - All categories with examples
5. **Transformation Engine** - Auto pattern selection
6. **Quality Metrics** - Measure and improve contexts
7. **13 Export Formats** - Universal compatibility
8. **LLM Integration** - OpenAI, Anthropic, Google
9. **Framework Integration** - LangChain, LlamaIndex
10. **Real-World Workflows** - 4 complete examples
11. **Advanced Techniques** - Multi-pattern, chaining
12. **Best Practices** - Production tips

**Time:** 2-3 hours (comprehensive)

---

## 🚀 Quick Start

### Option 1: Jupyter Notebook
```bash
jupyter notebook examples/getting_started.ipynb
```

### Option 2: VS Code
1. Open `.ipynb` file in VS Code
2. Select Python kernel
3. Run cells

### Option 3: JupyterLab
```bash
jupyter lab
# Navigate to examples/
```
